## Como revisar visualmente

1. `npm run dev:nostalgia` e `npm run dev:bible`.
2. Na home, a grade **Níveis** mostra as 25 artes; as fases 11–25 desbloqueiam na campanha (24 peças).
3. Abrir cada thumbnail e conferir: sem texto na ilustração, sem logo/franquia, foco legível em 24 peças.
4. `/?play=24` monta a primeira arte em 24 peças para checar recorte.

## Como regenerar as variantes

```bash
LOTE1_SRC=/caminho/arte-lote1 npm run assets:optimize
LOTE2_SRC=/caminho/arte-lote2 npm run assets:optimize:lote2
```

O lote 1 **não** apaga as entradas posteriores. O lote 2 **recusa** substituir um id do lote 1. Não copie os JPG originais para o git.
